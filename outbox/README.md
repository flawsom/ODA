runner (Ollama + Qwen3, no API keys):

- `<name>.hi.txt` — the Hindi translation (reference-standard passes applied)
- `<name>.response.md` — the formal response draft

See `forge-reports/FORGE_REPORT.md` for the per-letter report and ratings.
